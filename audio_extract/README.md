# Audio_extract
Python script to download audio from YouTube and direct links
- YouTube videos
- Direct audio links (MP3, WAV, AAC, etc.)

## How to Use
1. Clone the repo:
```bash
git clone https://github.com/YOUR_USERNAME/audio-downloader.git
```

## Install dependencies:
pip install -r requirements.txt

## Run the script:
python get_audio.py

## Folder Structure
```bash
audio_downloader_project/
├─ get_audio.py
├─ functions.py
├─ audios/           # downloaded files
├─ .gitignore
└─ README.md
```
